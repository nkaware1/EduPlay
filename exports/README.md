# مجلد الحزم المصدَّرة

ضع هنا ملفات zip التي تنزّلها من صفحة النشاط في المنصة:

- `activity-xxxxxxxx-desktop.zip` ← يُبنى منها ملف **EXE** لويندوز
- `activity-xxxxxxxx-android.zip` ← يُبنى منها ملف **APK** لأندرويد

ثم نفّذ `git add exports && git commit -m "add packs" && git push`
وسيبدأ سير العمل `Build apps (EXE / APK)` تلقائيًا. النتائج تظهر في تبويب **Releases** في المستودع.
