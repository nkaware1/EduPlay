# لمعة ✨ — منصة صناعة الأنشطة والألعاب التعليمية

منصة ويب عربية (RTL + English) للمعلمين: اختر قالبًا ← أدخل المحتوى ← عاين ← انشر رابطًا ورمز QR ← تابع نتائج الطلاب.

**التقنية:** React (Vite) + Node/Express + قاعدة بيانات **JSON** افتراضيًا، مع خيار **MongoDB** بتغيير متغير بيئة واحد.

## التشغيل السريع

يتطلب Node.js 18 أو أحدث.

```bash
npm run install:all        # تثبيت حزم الجذر والخادم والواجهة
cp server/.env.example server/.env
npm run dev                # الخادم :4000 والواجهة :5173
```

افتح http://localhost:5173 — عند أول تشغيل (وضع التطوير) تُنشأ بيانات تجريبية و3 حسابات:

| الدور | البريد | كلمة المرور |
|---|---|---|
| معلم | teacher@demo.com | teacher123 |
| طالب | student@demo.com | student123 |
| مدير | admin@demo.com | admin123 |

رمز الصف التجريبي للطلاب: `DEMO42`.

### الإنتاج (خادم واحد)
```bash
npm run build                       # يبني client/dist
NODE_ENV=production JWT_SECRET=... ADMIN_EMAIL=you@x.com ADMIN_PASSWORD=... npm start
```
الخادم يقدّم الواجهة والـ API من المنفذ نفسه. في وضع production لا تُنشأ حسابات تجريبية؛ يُنشأ المدير من `ADMIN_EMAIL/ADMIN_PASSWORD` فقط، و`JWT_SECRET` إجباري.

## قاعدة البيانات

| الخيار | الإعداد في `server/.env` |
|---|---|
| ملف JSON (افتراضي) | `DB_DRIVER=json` و`JSON_DB_PATH=./data/db.json` |
| MongoDB | `DB_DRIVER=mongo` و`MONGO_URI=mongodb://...` و`MONGO_DB_NAME=lamaa` |

الكود كله يتعامل مع واجهة موحّدة (`server/src/db/`): `find, findOne, insert, update, remove, removeWhere, count`.
لإضافة قاعدة أخرى (PostgreSQL، SQLite...) أنشئ ملف محوّل يطبّق نفس الدوال وسجّله في `db/index.js`؛ لا تحتاج لتغيير أي مسار.
نموذج البيانات مرن: جدول واحد `activities` يحمل `type` و`content` (JSON) لكل قالب، ويُتحقق من المحتوى عند النشر حسب نوع القالب (`server/src/validate.js`).

> محوّل MongoDB مكتوب لكنه **لم يُختبر** على خادم MongoDB حقيقي أثناء التطوير. جرّبه على قاعدة اختبار أولًا.

## أدوات إنشاء المحتوى (في محرر النشاط)

### ✨ التوليد بالذكاء الاصطناعي
المعلم يكتب موضوعًا (أو يلصق نص درس) ويحدد العدد والمرحلة والصعوبة واللغة، فيُولَّد المحتوى بالشكل المناسب للقالب، ويُعاين قبل أن يُضاف أو يستبدل المحتوى الحالي.
- **التفعيل:** أضف `ANTHROPIC_API_KEY` في `server/.env` (ويمكن ضبط `AI_MODEL` و`AI_MAX_PER_HOUR`). بدون المفتاح يبقى الزر ظاهرًا مع رسالة توضح السبب، وكل شيء آخر يعمل.
- يدعم **42 قالبًا** نصيًا (اختبارات، مطابقة، كلمات، حوار، شجرة قرارات، ألعاب تكسير الجمود...). القوالب التي تحتاج وسائط (الخرائط، الجيجسو، اكتشف الفروق، السودوكو، الذاكرة بالصور...) غير مدعومة.
- **الأمان والجودة:** الناتج يُتحقَّق منه بنفس مُتحقِّق النشر ويُعاد الطلب مرة واحدة عند الخطأ؛ لا تُقبل منه أي روابط وسائط؛ تُخلط خيارات الاختبارات (النماذج تميل لوضع الإجابة الصحيحة في موضع ثابت)؛ النص الملصوق يُعامل كمادة لا كتعليمات؛ حد أقصى للطلبات لكل معلم في الساعة.
- **الخصوصية:** الموضوع والنص يُرسلان إلى واجهة Anthropic. نبّه المعلمين ألا يضعوا بيانات طلاب.
- راجع المحتوى المولَّد دائمًا (قد يخطئ النموذج في معلومة أو في سلسلة كلمات).

### 📥 الاستيراد من Excel / CSV
ملف `xlsx` أو `csv`/`tsv`، أو **لصق مباشر من Excel**. يعرض الأعمدة المطلوبة لكل قالب، ويوفّر **ملفًا نموذجيًا للتنزيل**، ويعاين الصفوف ويتجاهل الصفوف الخاطئة مع سبب كل منها، ثم **إضافة** أو **استبدال**. يدعم 39 قالبًا. يكتشف الفاصل تلقائيًا (فاصلة، فاصلة منقوطة كما في Excel العربي، Tab) ويتعامل مع الاقتباس والأسطر المتعددة. ملفات `xls` القديمة غير مدعومة (احفظها xlsx).

### 🔁 التبديل بين القوالب
زر «تحويل إلى قالب آخر» يعرض القوالب المتوافقة مع محتواك فقط مع عدد العناصر الناتج. أمثلة: اختيار من متعدد ← مطابقة/بطاقات/ألغاز/سباق/مليون/متاهة/كلمات متقاطعة؛ مطابقة ← اختبار؛ ألغاز ← مشنوق/غرفة هروب؛ قائمة كلمات ← عجلة/بحث عن كلمات/بنغو؛ شجرة قرارات ↔ لعب أدوار. الحقول الخاصة بالقالب القديم (كالصور) قد تُفقد، ويُطلب تأكيد قبل التحويل (وتحذير إضافي للنشاط المنشور). التغيير يُحفظ مع الحفظ التلقائي.

## 🔴 اللعب الجماعي المباشر (برمز PIN كما في Kahoot)

من صفحة النشاط (بعد نشره) اضغط **«لعب مباشر مع الطلاب»**. تظهر شاشة المعلم برمز من 6 أرقام ورمز QR، ويدخل الطلاب من أي جهاز عبر **`/join`** (أو زر «انضم برمز» في أعلى الموقع) بالرمز والاسم، دون حساب.

| الوضع | القوالب | كيف يعمل |
|---|---|---|
| **مسابقة مباشرة** | كل قوالب الأسئلة (اختيار من متعدد، النجوم، الضفدع، المليون، الاختبار السريع، صح/خطأ، الغريب، النمط، ثلاث حقائق...) و**ملوك المعرفة** | المعلم يعرض السؤال والكل يجيب معًا. النقاط بالسرعة والدقة مع مكافأة التتابع، ثم كشف الإجابة وترتيب مباشر ولوحة شرف. في «ملوك المعرفة» ينضم الطلاب إلى **فرق** وتُجمَّع نقاطها |
| **سباق** | نفس القوالب (الافتراضي لقالب سباق السيارات) | كل طالب يجيب بسرعته وتتقدم سيارته عند كل إجابة صحيحة، والخطأ يفرض عقوبة 3 ثوانٍ. يفوز أول من يبلغ الهدف |
| **تصويت حي** | التصويت، سؤال أم خيار | النتائج تتحدث لحظيًا على شاشة المعلم، ويمكنه إخفاءها عن الطلاب |
| **لوحة مشتركة** | لوحة العصف الذهني | يضيف الطلاب ملاحظات في أعمدة ويصوّتون 👍 ويراها الجميع فورًا. للمعلم حذفها وإغلاق الإضافة وإخفاء الأسماء |

- **النتائج:** عند انتهاء المسابقة/السباق تُحفظ درجة كل لاعب في صفحة «النتائج» للمعلم (ويمكن تصديرها CSV).
- **الأمان:** منطق اللعبة كله على الخادم؛ اللاعب **لا يتلقى الإجابة الصحيحة** قبل الكشف، والمؤقت والدرجات يحسبها الخادم، ولا يتحكم باللعبة إلا المعلم صاحبها. الأسماء تُنظَّف، وتخمين الرموز محظور بعد عدة محاولات، والرسائل محدودة المعدل، ويمكن للمعلم طرد لاعب أو إغلاق الانضمام.
- **الاتصال:** يعيد الطالب والمعلم الاتصال تلقائيًا (أو بعد تحديث الصفحة) ويستعيدان جلستهما.
- **حدود:** الجلسات في **ذاكرة الخادم** (تنتهي بإعادة تشغيله، وتُغلَق تلقائيًا بعد 3 ساعات خمول)، ويلزم **خادم واحد**؛ للتوسع لعدة خوادم يلزم محوّل Redis لـ Socket.IO. الحد 300 لاعب لكل جلسة و5 جلسات لكل معلم. خلف وكيل عكسي (Nginx) فعّل WebSocket.
- **اختبار البروتوكول:** `npm run test:live --prefix server` (على قاعدة بيانات جديدة والخادم يعمل) يشغّل 71 فحصًا، منها الأمان.

## تصدير الأنشطة (ويب · EXE · APK)

من صفحة النشاط (للمالك، أو لأي نشاط عام):

| الصيغة | الناتج | هل يُبنى جاهزًا؟ |
|---|---|---|
| 🌐 صفحة ويب | ملف `.html` واحد مستقل (المشغّل + المحتوى + الصور المرفوعة مضمّنة) يعمل بلا إنترنت | **نعم** — افتحه مباشرة أو ارفعه لأي استضافة |
| 🖥️ سطح المكتب | مشروع Electron جاهز (`zip`) | يحتاج `npm install && npm run dist` على جهازك لإنتاج `exe` |
| 📱 أندرويد | مشروع Capacitor جاهز (`zip`) | يحتاج Android Studio لإنتاج `apk` (الخطوات في README داخل الحزمة) |

لا يمكن للخادم نفسه إنتاج `exe` أو `apk` مباشرة لأن ذلك يتطلب أدوات بناء (Electron وAndroid SDK) ثقيلة. النسخة المستقلة لا ترسل النتائج لأي خادم (تظهر للطالب فقط).
البناء: `npm run build` ينتج الواجهة **و**مشغّل التصدير (`client/dist-player`)؛ بدونه يفشل التصدير بخطأ 503.

### البناء التلقائي لـ EXE وAPK (GitHub Actions)
بدل تثبيت Node وAndroid Studio على جهازك، يبني **GitHub** الملفات لك مجانًا (مستودع عام، أو حصة الدقائق المجانية للمستودع الخاص):

1. أنشئ مستودعًا على GitHub وادفع إليه هذا المشروع (أو انسخ فقط المجلدين `.github/` و`exports/` إلى مستودع جديد فارغ).
2. من صفحة النشاط نزّل **حزمة سطح المكتب** و/أو **حزمة أندرويد** وضعها كما هي (دون فك الضغط) في مجلد `exports/`.
3. `git add exports && git commit -m "add packs" && git push`
4. في تبويب **Actions** يبدأ `Build apps (EXE / APK)` تلقائيًا، وتجد الملفات الناتجة في **Releases** (أو في Artifacts أسفل صفحة التشغيل).

- يُبنى فقط ما أُضيف أو عُدِّل في كل push. يمكن أيضًا تشغيله يدويًا (Run workflow) وإلصاق رابط حزمة عامة من منصتك.
- الأسماء يجب أن تنتهي بـ `-desktop.zip` أو `-android.zip` (هكذا تُنزَّل أصلًا).
- ملف EXE من نوع **portable** (يعمل بنقرتين دون تثبيت) وبأيقونة Electron الافتراضية. ملف APK من نوع **debug** (يُثبَّت مباشرة على الأجهزة، لكنه غير صالح للنشر على Google Play الذي يتطلب توقيعًا).
- كلاهما **غير موقَّع رقميًا**، فقد يعرض ويندوز تحذير SmartScreen وأندرويد تحذير «مصدر غير معروف».

## هيكل المشروع

```
server/src/  config · db/ (json, mongo) · routes/ · auth.js · validate.js · seed.js
client/src/  pages/ · games/ (GameShell + 3 ملفات ألعاب) · templates/ (meta, defaults, editors) · i18n · api
```

### إضافة قالب جديد
1. `client/src/templates/meta.js`: أضف الاسم والوصف واللون ودالة `count`.
2. `defaults.js`: المحتوى الابتدائي. `editors.jsx` أو `editorsExtra.jsx`: محرر المحتوى.
3. `client/src/games/*.jsx`: مكوّن اللعبة `({content, s, report, finish, snd, t})` وسجّله في `players`.
4. `server/src/validate.js`: دالة التحقق + `LIST_KEY`.

## الصلاحيات والأمان
- معلم: ينشئ ويدير أنشطته وصفوفه ويرى نتائج أنشطته فقط. طالب: يلعب وينضم للصفوف بالرمز ويرى نتائجه. مدير: يدير المستخدمين والأنشطة. لا يمكن إنشاء مدير من التسجيل العام.
- النشاط غير المنشور لا يراه غير صاحبه. النتائج وتصدير CSV لصاحب النشاط والمدير فقط. تصدير CSV محمي من حقن الصيغ.
- كلمات المرور مشفّرة (bcrypt)، وJWT لمدة 14 يومًا، وتحديد معدل للتسجيل ولإرسال النتائج.
- رفع الملفات (صور/صوت/فيديو حتى 8MB): للمعلمين فقط، والنوع يُتحقق منه ولا يُسمح بـ SVG/HTML.

## حدود يجب معرفتها
- **التصحيح يتم في متصفح الطالب** (الإجابات الصحيحة موجودة في بيانات النشاط). الخادم يضمن حدود النتيجة (لا تتجاوز الإجمالي) وعدد المحاولات، لكنه لا يمنع طالبًا متمكنًا من التلاعب بنتيجته. مناسب للتدريب والواجبات العادية، وليس للاختبارات الرسمية.
- المحاولات المحدودة للطالب غير المسجّل تُحتسب بالاسم المكتوب، ويمكن تجاوزها بتغيير الاسم.
- ملف JSON مناسب لمئات المستخدمين وليس لآلاف؛ انتقل إلى MongoDB عند النمو.
- التوليد بالذكاء الاصطناعي اختُبر مقابل خادم محاكاة يطابق شكل واجهة Anthropic وليس مقابل الخدمة الفعلية (لا يوجد مفتاح أثناء التطوير). جرّبه بمفتاحك قبل الاعتماد عليه.
- سير عمل GitHub Actions: اجتاز فحص `actionlint`، وجُرّبت خطوة التخطيط محليًا، وبُنيت حزمة سطح المكتب فعليًا (هدف لينكس بنفس الإعدادات) وشُغّل التطبيق الناتج. **لم يُشغَّل على GitHub نفسه**، ولم يُبنَ هدف ويندوز `portable` ولا خطوة Gradle لـ APK لعدم توفر ويندوز/شبكة Gradle هنا. قد تحتاج تعديلًا بسيطًا في أول تشغيل.
- الإملاء يستخدم نطق المتصفح (جودة الصوت العربي تختلف بين الأجهزة) أو ملفًا صوتيًا ترفعه.
- ترجمة الإنجليزية تغطي الواجهة والألعاب؛ رسائل أخطاء الخادم بالعربية فقط.
